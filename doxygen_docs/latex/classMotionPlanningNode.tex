\doxysubsection{Detailed Description}
ROS node for joint-\/space motion execution. 

This class implements a lightweight motion execution layer that converts joint-\/space targets into smooth reference trajectories for the robot controller. Motions are executed using cubic time scaling to ensure continuous velocity profiles.

The node is designed to be triggered by a higher-\/level task planner and provides a latched acknowledgement signal upon completion of each motion.
