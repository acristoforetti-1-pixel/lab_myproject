\doxysubsection{Detailed Description}
ROS node for 6D pose estimation of rigid blocks using RGB-\/D and YOLOv8. 

This ROS node performs perception for pick-\/and-\/place tasks by combining deep-\/learning-\/based object detection using YOLOv8 on RGB images with geometric processing of depth data.

It estimates the 3D position and yaw orientation of rigid, non-\/deformable blocks placed on a planar surface. Detected object poses are expressed in the robot base frame and published to the /vision namespace for consumption by task planning and motion planning modules.

Main features\+:
\begin{DoxyItemize}
\item YOLOv8 object detection on RGB images
\item Robust depth sampling inside bounding boxes
\item Table plane height estimation
\item 3D position estimation using robust statistics
\item Yaw estimation using geometric analysis (min\+Area\+Rect / PCA)
\item Optional request-\/based pose publication 
\end{DoxyItemize}
