\doxysubsection{Detailed Description}
Task-\/level pick-\/and-\/place planning with inverse kinematics. 

This ROS node implements a complete pick-\/and-\/place pipeline for a UR5 robotic arm. It receives object poses from the perception system, computes feasible grasp configurations using inverse kinematics, and generates a sequence of joint-\/space targets to execute grasp, transport, and placement motions.

The node performs decision making at task level, including\+:
\begin{DoxyItemize}
\item Grasp orientation selection
\item Singularity and joint-\/jump avoidance
\item Class-\/dependent placement strategy
\item Motion synchronization via acknowledgements
\end{DoxyItemize}

Inverse kinematics is solved using the KDL library, while trajectory execution is delegated to a dedicated motion execution node.
