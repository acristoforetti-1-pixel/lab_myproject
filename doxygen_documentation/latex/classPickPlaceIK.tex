\doxysubsection{Detailed Description}
Provides task-\/level pick-\/and-\/place motion planning using KDL IK. 

This class subscribes to joint states and object poses and publishes joint targets for the UR5 manipulator. It computes feasible trajectories for grasping, transporting, and placing objects using inverse kinematics.
